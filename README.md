# The Reading Room

A little corner of my learning journey. These are the books that have challenged my thinking, helped me explore new ideas, and shaped the way I approach building things.

## Run

```sh
pnpm install
pnpm dev
```

## Add a book

1. Put the cover (and spine, if you have one) in `public/books/`.
2. Add an entry to `src/data/books.ts`.

No spine image? The shelf draws one from `color` and `foil`.

## Edit your details

Name, bio and links are in `src/data/profile.ts`.

## Build

```sh
pnpm build
```
